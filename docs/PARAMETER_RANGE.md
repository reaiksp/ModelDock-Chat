# 模型参数范围 / Model parameter range

参数条覆盖 **0.5B–48B，每格0.5B**，共96个位置。它是参数上限，取不超过上限的最近已核对模型档，界面显示实际参数；不伪造任意大小的模型。拖动参数条会进入压缩模型推荐，但不下载、不切换聊天模型。精度和对话需求以及语音资源共同决定推荐；资源不足只在该参数模型内降精度，不自动更换参数档。

已核对家族：0.5、0.6、1.5、1.7、3、4、7、8、14、27、32、46.7B。48B端点目前匹配46.7B Mixtral MoE（总参数，不是激活参数）；不是原生48B权重。32B和46.7B没有接入可核对的单文件原精度版本，5档会显示可用的较低精度。其它家族5档为发布者的F16/BF16，不宣称与训练原始权重逐位相同。小参数模型不一定更准确，参数量不等于下载体积或激活计算量。

下载为固定发布版本的精确文件，长度和SHA-256核对后通过Ollama CLI导入，保留原有分段续传与已有权重核对。当前新增文件只核对上游元数据，未全量下载推理；实际部署必须成功加载才保存方案。记忆和黑话继续使用已确认记录检索／系统提示持久化，不是权重训练，质量需实际验收。用户原文、人格、资料、API供应商及旧方案保留。API模式不使用本地参数条。

新家族8K/16K/32K额外运行估算为3/8/16GiB；27B保留已有预算。估算不是硬件性能承诺。

English: The continuous parameter cap spans0.5B–48B in0.5B steps.
